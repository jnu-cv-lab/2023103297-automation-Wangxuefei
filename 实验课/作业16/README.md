# 相机标定实验 - 棋盘格标定

## 项目简介

本项目使用棋盘格图案对相机进行标定，通过采集多张不同姿态的棋盘格图像，估计相机的内参矩阵、畸变参数和外参，并输出去畸变结果。重投影误差为 **0.4234 像素**，标定精度优秀。

## 实验环境

- **操作系统**: Ubuntu / Linux
- **Python版本**: 3.12
- **依赖库**:
  - OpenCV 4.x
  - NumPy
  - Matplotlib

## 运行方法

### 1. 安装依赖

```bash
pip install opencv-python numpy matplotlib
```

### 2. 准备标定图片

将标定图片放入 `images/` 目录，支持 `.jpg`、`.jpeg`、`.png`、`.bmp` 格式。

**拍摄要求：**
- 至少 15 张不同姿态的图片
- 覆盖图像的不同区域（中心、四角、边缘）
- 包含不同距离和倾斜角度
- 棋盘格保持平整，避免模糊和反光

### 3. 运行程序

```bash
python src/main.py
```

### 4. 查看结果

所有输出文件保存在 `output/` 目录中。

## 去畸变效果

由于畸变参数较小（\|k1\|=0.11），去畸变处理有一定效果但视觉差异不明显，主要体现在：
- 图像边缘轻微桶形畸变得到校正
- 四角区域的形状更趋于真实
- 中心区域几乎无变化

这反映了该手机摄像头镜头畸变控制良好。

## 改进建议

1. **增加图片数量**：采集 20-30 张不同姿态图片
2. **丰富姿态变化**：增加更极端的角度和距离
3. **覆盖图像边缘**：让棋盘格出现在图像四角区域
4. **保证图像质量**：避免模糊、反光和过曝
5. **保持棋盘格完整**：确保所有角点在图像内可见
