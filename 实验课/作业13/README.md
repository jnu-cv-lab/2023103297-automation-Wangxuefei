# CIFAR-10 CNN 图像分类实验

## 项目简介

本项目基于CIFAR-10数据集，使用PyTorch框架实现了一个自定义CNN模型，完成了图像分类任务。通过实验深入分析了优化器、学习率对模型训练的影响，并实现了卷积核可视化、特征图分析、错误样本分析和混淆矩阵评估等深度学习模型分析技术。

## 实验环境

| 项目 | 配置 |
|------|------|

| 深度学习框架 | PyTorch |
| 数据集 | CIFAR-10 |
| 硬件 | CPU |
| 训练轮数 | 10 epochs |
| 批次大小 | 64 |

## 模型架构

自定义CNN模型包含以下层：

```
CIFAR10_CNN(
  ├─ Conv2d(3, 32, kernel_size=3, padding=1)
  ├─ BatchNorm2d(32)
  ├─ MaxPool2d(2, 2)
  ├─ Conv2d(32, 64, kernel_size=3, padding=1)
  ├─ BatchNorm2d(64)
  ├─ MaxPool2d(2, 2)
  ├─ Conv2d(64, 128, kernel_size=3, padding=1)
  ├─ BatchNorm2d(128)
  ├─ MaxPool2d(2, 2)
  ├─ Linear(128*4*4, 256)
  ├─ Dropout(0.5)
  ├─ Linear(256, 128)
  ├─ Dropout(0.5)
  └─ Linear(128, 10)
)
```

**模型参数量**：约42万

## 实验任务

### 任务1：CNN模型训练

使用CIFAR-10数据集训练CNN模型，记录训练和验证过程中的损失函数和准确率变化。

**训练结果**：
- 训练准确率：67.89%
- 验证准确率：71.88%
- 测试准确率：73.70%
- 训练时间：349.29秒

### 任务2：优化器对比实验

对比三种优化器的训练效果：
- SGD（学习率=0.01）
- SGD+Momentum（学习率=0.01，动量=0.9）
- Adam（学习率=0.001）

**实验结果**：

| 优化器 | Training Loss | Validation Loss | Training Acc | Validation Acc | Test Acc |
|--------|---------------|-----------------|--------------|----------------|----------|
| SGD | 1.1113 | 1.0153 | 60.42% | 63.50% | 66.11% |
| SGD+Momentum | 0.9261 | 0.8264 | 68.31% | 71.02% | 72.69% |
| Adam | 0.9461 | 0.8011 | 67.89% | 71.88% | **73.70%** |

**结论**：Adam优化器表现最佳，SGD+Momentum次之，标准SGD效果最差。

### 任务3：学习率对比实验

固定使用Adam优化器，对比不同学习率的效果：
- 0.1
- 0.01
- 0.001

**实验结果**：

| 学习率 | Training Acc | Validation Acc | Test Acc | 现象 |
|--------|--------------|----------------|----------|------|
| 0.1 | 9.74% | 10.35% | 10.00% | 梯度爆炸，无法收敛 |
| 0.01 | 41.72% | 44.74% | 46.15% | 收敛缓慢，欠拟合 |
| 0.001 | 67.89% | 71.88% | **73.70%** | 收敛良好，效果最佳 |

**结论**：学习率0.001是最佳选择，学习率过大导致无法收敛，过小则收敛缓慢。

### 任务4：卷积核可视化

- 不同卷积核关注不同的图像特征（颜色、边缘、纹理）

## 实验结论

### 最佳配置

| 参数 | 推荐值 |
|------|--------|
| 优化器 | Adam |
| 学习率 | 0.001 |
| 预期测试准确率 | ~73-74% |

### 主要发现

1. **优化器选择**：Adam > SGD+Momentum > SGD
2. **学习率影响**：0.001是最佳选择，过大导致发散
3. **特征学习**：CNN自动学习边缘、纹理、颜色等低级特征
4. **主要错误**：猫-狗、鹿-猫等视觉相似类别易混淆

### 改进建议

| 方面 | 建议 |
|------|------|
| 数据层面 | 增加易混淆类别样本；使用数据增强（旋转、缩放、颜色抖动） |
| 模型层面 | 使用更深网络（ResNet、DenseNet）；引入注意力机制 |
| 训练策略 | 学习率调度；类别权重或Focal Loss；标签平滑 |
| 后处理 | 模型集成；测试时增强（TTA） |
