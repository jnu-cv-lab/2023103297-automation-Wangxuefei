# 图像几何变换实验

## 实验目的

研究三种几何变换（相似变换、仿射变换、透视变换）对图像几何性质的影响，包括：
- 直线是否保持为直线
- 平行线是否保持平行
- 垂直线是否保持垂直
- 圆是否保持为圆

最后，对存在透视畸变的平面图像进行校正。

## 实验结果

### 几何性质总结

| 变换类型 | 直线保持直线 | 平行线保持平行 | 垂直线保持垂直 | 圆保持为圆 |
|---------|-------------|---------------|---------------|-----------|
| 相似变换 | ✓ 是 | ✓ 是 | ✓ 是 | ✓ 是 |
| 仿射变换 | ✓ 是 | ✓ 是 | ✗ 否 | ✗ 变椭圆 |
| 透视变换 | ✓ 是 | ✗ 否 | ✗ 否 | ✗ 变曲线 |

### 理论解释

1. **直线保持性**：三种变换都是射影变换的子集，都保持直线（射影几何基本性质）

2. **平行保持性**：
   - 相似变换：保持平行（旋转、缩放不改变方向关系）
   - 仿射变换：保持平行（平行线映射后仍平行）
   - 透视变换：不保持平行（平行线会相交于灭点）

3. **垂直保持性**：
   - 相似变换：保持垂直（角度不变）
   - 仿射变换：不保持垂直（会改变角度）
   - 透视变换：不保持垂直（投影改变角度关系）

4. **圆保持性**：
   - 相似变换：圆仍为圆
   - 仿射变换：圆变为椭圆
   - 透视变换：圆变为二次曲线

## 输出示例

### 测试图变换结果

运行后会在 `output/` 文件夹生成以下图像：

| 文件名 | 说明 |
|-------|------|
| `0_original.png` | 原始测试图（600×600） |
| `1_similarity.png` | 相似变换后（旋转+缩放） |
| `2_affine.png` | 仿射变换后（拉伸+剪切） |

### 透视校正结果

| 文件名 | 说明 |
|-------|------|
| `corners_detected.png` | 自动检测的纸张角点 |
| `corrected.png` | 校正后的A4纸正视图 |
| `correction_comparison.png` | 校正前后对比 |

## 注意事项

**透视校正照片要求**：
   - 白纸放在深色背景上（对比度明显）
   - 光线均匀，避免强阴影
   - 纸张四个角完整可见
   - 纸张周围无杂物
